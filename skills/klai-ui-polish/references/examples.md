# Worked examples (illustrative, do not copy)

## Desk admin table
**Ask:** "The jobs table looks messy but keep our green and the current pages."
**Choose polish.** Direction already implied (keep green, keep pages).
**Audit:** impact 1 — assign clipped at 390; impact 2 — no row focus; impact 3 — mixed 13px gaps; leftover indigo on a secondary button.
**Passes:** spacing → colour execution (secondary uses text role, accent stays green) → type tabular times → table sticky header and inner horizontal scroll at 390 → focus rings.
**Not done:** changing the nav model, adding a board view (makeover/remix).

## Cover only
**Ask:** "The splash is loud; inner app is fine."
**Polish the cover** if the identity stays; **makeover** if they want a different cover world. Inner operate pages out of scope.

## Wrong skill
**Ask:** "Make it feel like a different product, same buttons."
That is a makeover. If you already started a polish audit, stop after baseline and hand off. Do not retint the discarded look.
