# Worked examples (illustrative, do not copy)

## Desk admin table
**Ask:** "The jobs table looks messy but keep our green and the current pages."
**Choose polish.** Direction already implied (keep green, keep pages).
**Audit:** impact 1 — assign clipped at 390; impact 2 — no row focus / contrast on the late flag; impact 3 — mixed 13px gaps; leftover indigo on a secondary button.
**Passes:** unclip Assign at 390 and restore visible row focus (action/accessibility first) → spacing → colour execution (secondary uses text role, accent stays green) → type tabular times → table sticky header and inner horizontal scroll at 390.
**Do not:** click Assign against the connected jobs backend unless the user authorized that consequential action; the polish check is that the control is visible, labelled, focused, and unclipped. Keep the route id; if the caption was "Go", you may relabel to "Assign" without renaming the action.
**Not done:** changing the nav model, adding a board view (makeover/remix).

## Cover only
**Ask:** "The splash is loud; inner app is fine."
**Polish the cover** if the identity stays; **makeover** if they want a different cover world. Inner operate pages out of scope.

## Wrong skill
**Ask:** "Make it feel like a different product, same buttons."
That is a makeover. If you already started a polish audit, stop after baseline and hand off. Do not retint the discarded look.
