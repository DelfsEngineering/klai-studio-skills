# Scenario: desk-based admin app
Setup: a data-dense back-office app used at a desk on large screens, with tables, filters and forms.

Expected:
- Profile drives a dense, scannable layout; the run does not reuse a mobile-first or decorative direction by default.
- Tables and filters keep every column, filter and bulk action (parity).
- Quality pass starts at desktop width, then tablet and phone.
- One theme unless the profile gives a reason for a second.
